# Hypotenuse Calculator

A beginner-friendly Python project that calculates the hypotenuse of a right triangle based on the lengths of the opposite and adjacent sides.

## Features

- Accepts the lengths of two sides of a right triangle
- Applies the Pythagorean theorem
- Calculates the hypotenuse
- Displays the result formatted to two decimal places

## Technologies Used

- Python 3
- Built-in `math` module

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/hypotenuse-calculator.git
```

2. Navigate to the project folder:

```bash
cd hypotenuse-calculator
```

3. Run the script:

```bash
python main.py
```

## Example

### Input

```text
Enter the opposite side: 3
Enter the adjacent side: 4
```

### Output

```text
The hypotenuse of the triangle with opposite side 3.00 and adjacent side 4.00 is 5.00
```

## Learning Objectives

This project demonstrates:

- User input handling
- Mathematical calculations
- Using the `math` module
- Applying the Pythagorean theorem
- Formatted output

## Mathematical Concept

The calculation is based on the Pythagorean theorem:

a² + b² = c²

Where:
- `a` = opposite side
- `b` = adjacent side
- `c` = hypotenuse
